# 分類與平台規則

Novae 的提案與設備報修分類是安裝後的動態資料，不是 repository 內的硬編碼或 JSON。首次部署完成後，由 `ADMIN_EMAILS` 對應的首位平台管理員登入並完成引導設定；之後在「系統設定」隨時維護與調整。

## 首次設定

1. 完成後端與前端部署。
2. 使用 `ADMIN_EMAILS` 中的帳號首次登入。
3. **步驟 1**：確認介面語言；系統會依瀏覽器／作業系統首選語言預選，也可在繼續前切換。
4. **步驟 2**：在提案／設備切換介面中選擇要啟用的平台功能。兩者預設啟用；也可只啟用其中一項，或兩者都關閉而只使用公告。
5. **步驟 3**：使用與系統設定相同的分類清單與編輯表單，為每個已啟用功能建立至少一個分類，填入永久且唯一的 ID、顯示名稱並指定唯一預設分類。
6. 提案分類另可設定閱讀範圍、作者顯示、附議門檻／天數與回覆天數。
7. 按下完成時會先提示負責人指派已暫時略過；等其他相關負責人完成註冊並首次登入後，再到「系統設定 → 人員與管理權限」指派。

未啟用的功能不要求填寫分類；之後可在「系統設定 → 分類與處理流程」隨時開啟。

## 平台功能開關

| 功能 | 關閉後的行為 |
| --- | --- |
| 提案 | 側欄與手機導覽隱藏提案入口；既有提案、分類與權限保留 |
| 設備報修 | 側欄與手機導覽隱藏設備入口；既有報修、分類與權限保留 |
| 公告留言 | 所有既有與新公告停止新增／回覆留言；公告與既有留言仍可閱讀 |

公告入口不受提案／設備開關影響；公告留言另有全域總開關。開關變更與分類草稿會在系統設定中整批原子化儲存，失敗時全數回滾。

## 規則何時能修改

| 規則 | 建立後 | 影響範圍 |
| --- | --- | --- |
| 分類 ID | 鎖定 | 保護既有網址、關聯與通知 |
| 閱讀範圍 | 永久鎖定 | 避免既有內容因改設定意外曝光 |
| 作者顯示 | 永久鎖定 | 避免匿名承諾被日後改寫 |
| 留言開關 | 可修改 | 分類總開關即時限制既有提案；單筆 override 保留手動／結案關閉 |
| 公告留言總開關 | 可修改 | 即時限制所有公告；單筆 override 保留手動關閉 |
| 附議與期限 | 可修改 | 只影響之後建立的新提案 |
| 名稱與標籤 | 可修改 | 立即更新分類顯示 |
| 平台功能開關 | 可修改 | 只影響導覽與新入口；既有資料保留 |

## 閱讀範圍

- `school`（校內可讀）：已登入且符合校內網域的使用者可讀。
- `reviewed-school`（審核後校內可讀）：審核前僅作者與管理員可讀，通過後才進入校內公開列表。
- `owner-admin`（作者與管理員）：內容只供作者與該分類管理員處理；作者身分固定對管理端可見（私密權益案件）。

這些存取限制完全由資料庫與 Cloudflare Worker 函數強制執行，不依賴前端視覺隱藏。

## 分類管理員與通知

在「系統設定 → 人員與管理權限」中：
1. 先選提案分類、設備分類或公告功能。
2. 查看該範圍目前已指派的負責人名單。
3. 透過姓名、Email 或 UID 精確查找已註冊使用者進行指派或撤銷；同一人可負責多個分類，同一分類也可多人共同管理。
4. 新提案與設備報修通知只會發送給該分類明確指派的負責人（排除案件作者本人）。平台總管理員名單僅由後端環境變數 `ADMIN_EMAILS` 決定。

## 平台設定（媒體限制與資料生命週期）

平台總管理員可在「系統設定 → 平台設定」調整全站媒體與資料保留政策：

### 1. 圖片上傳限制
- **提案圖片上限**：預設 2 張。
- **設備回報圖片上限**：預設 2 張。
- **公告圖片上限**：預設 10 張。
- **單檔大小上限**：預設 5 MB，客戶端在上傳前會以 WASM（WebAssembly）自動壓縮並轉為 WebP 格式。

### 2. 資料保留排程 (Data Retention Lifecycle)
- **已結案案件保留期限**：預設 180 天。結案逾期後，系統背景排程會自動永久清理案件主體、留言、附議紀錄及關聯的 Cloudinary 圖片資源。公告則永久保留。
- **審計日誌保留期限**：預設 365 天，自動清理逾期管理日誌。
- **未活躍個資與無效推播裝置清理**：長期未活動帳號個資與無效 FCM Token 會由背景排程自動清理，避免過度保留。

## 驗收清單

1. 為公開、審核後公開與私密提案分類各建立一件測試提案，確認權限隔離有效。
2. 測試關閉分類留言與公告總留言開關，確認留言即時鎖定。
3. 指派分類負責人並送出案件，確認只有被指派的人收到建立通知。
4. 於平台設定調整上傳張數限制，確認前台即時套用且上傳符合上限。
5. 刪除測試分類，確認其下案件與圖片資源已完整清理。
